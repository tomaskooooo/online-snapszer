# Card images

Taken from https://github.com/tomasdrus/hungarian-playing-cards (folder `cards-medium`, 181x293 px PNG,
Hungarian 32-card deck, the 7s and 8s are left out because the game does not use them).

That repository declares no license, so the reuse terms are unknown. Ask the author
(https://github.com/tomasdrus) for permission, or swap in a deck with a clear license,
before putting this game on a public site.

The four suit symbols (suit-acorn.png, suit-bell.png, suit-heart.png, suit-leaf.png) are the `large` icons from the same repository's suit-icons folder, with the same unknown license.
